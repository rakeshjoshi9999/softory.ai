# Triage signals — runs nightly (turn on in Phase 3)

1. Read new feedback since the last run from GitHub Discussions (category "Feedback") and any
   connected feedback channels.
2. Deduplicate against open issues and earlier feedback. Link duplicates instead of
   creating new issues.
3. For each clear, in-scope request: open an issue with acceptance criteria, label it
   `from-feedback` and `triage`, and link it to the matching roadmap item.
4. List unclear or out-of-scope requests in one issue `Triage <date>` labelled `needs-human`.
   Never close, reject or reply to feedback yourself.
