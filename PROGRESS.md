# Progress

Progress now lives on GitHub, where the factory loop records it:
- **What's next / in progress:** open issues labelled `ready` / `in-progress`, ordered by task ID.
- **What's done:** closed issues and merged PRs. Each PR carries the run's result and token stats.
- **Waiting for a human:** issues and PRs labelled `needs-human` or `blocked`, and `Gate n review` issues.
